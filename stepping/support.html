1. 시작하기

核心循环：把"大事"拆成"一步"

The core loop: big task → one step

核心の流れ：大きなこと → 一つのステップ

핵심 루프: 큰 일 → 한 단계

1
新建任务，写下让你卡住的那件大事（如"准备季度汇报"）。
Create a task and write the big thing that freezes you (e.g. "Q3 report").
新しいタスクを作成し、行き詰まっている大きなこと（例：「四半期報告の準備」）を書きます。
새 작업을 만들고 막히는 그 큰 일(예: "분기 보고 준비")을 적습니다.
2
用 AI 拆解 把它分成几个具体小步，或直接手写得更细。
Use AI Breakdown to split it into concrete steps, or write them yourself.
AI分解 で具体的な小ステップに分けるか、自分で細かく書きます。
AI 분해로 구체적인 작은 단계로 나누거나 직접 더 세분화해 씁니다.
3
点 今日聚焦 把今天最重要的 ≤3 件标星，一次只看一件事。
Tap Today Focus to star ≤3 most important tasks; see one thing at a time.
今日のフォーカス で今日の最重要（最大3件）に星を付け、一度に一つのことだけ見ます。
오늘의 집중에서 오늘 가장 중요한 ≤3개에 별표를 하고 한 번에 한 가지씩 봅니다.
4
开 引导专注，一次只做当前这一步，做完再看下一个。
Start Guided Focus — do only the current step, then move on.
ガイド集中 を開始し、今のステップだけを行い、終わってから次へ進みます。
가이드 집중을 켜고 현재 단계만 하고, 끝나면 다음을 봅니다.

试用期怎么算？5 天结束后还能用吗？ How does the trial work? Can I still use it after 5 days? 試用期間はどう計算されますか？5日後も使えますか？ 체험 기간은 어떻게 계산되나요? 5일 후에도 사용할 수 있나요?

首次启动起 5 天（120 小时）为 Pro 体验期，期间全部功能无限使用。体验期结束后转为免费版：基础任务管理、语音速记、心情、番茄钟、小组件全部免费；仅 AI 每天 2 次、引导专注每天 2 次、PDF 导出、5 个高级洞察板块 受限。
提示首装时间写入 Keychain，卸载重装不会重置试用期。

The first 5 days (120h) after first launch are the Pro trial — everything unlimited. After that, free tier keeps core features (tasks, voice, mood, pomodoro, widgets); only AI 2×/day, Guided Focus 2×/day, PDF export, and 5 advanced insight panels are limited.
TipInstall time is in Keychain, so reinstalling won't reset the trial.

初回起動から 5日間（120時間）が Pro 体験期間で、期間中は全機能を無制限に利用できます。終了後は無料版に移行し、基本タスク管理・音声メモ・気分・ポモドーロ・ウィジェットはすべて無料、制限されるのは「AI 1日2回・ガイド集中 1日2回・PDF出力・高度インサイト5項目」のみです。
ヒント初回インストール日時は Keychain に保存され、アンインストールして再インストールしても試用期間はリセットされません。

최초 실행부터 5일(120시간)이 Pro 체험 기간이며, 기간 중 전 기능 무제한 사용 가능합니다. 종료 후 무료판으로 전환되어 기본 작업 관리·음성 메모·기분·뽀모도로·위젯은 모두 무료이며, 제한되는 것은 'AI 하루 2회·가이드 집중 하루 2회·PDF 내보내기·고급 인사이트 5개'뿐입니다.
팁최초 설치 시점은 Keychain에 저장되어 앱을 지웠다 다시 깔아도 체험 기간이 초기화되지 않습니다.

为什么 AI / 引导提示"次数用完了"？ Why does it say "quota used up"? なぜAI・ガイドで「回数がなくなりました」と表示されるのですか？ 왜 AI/가이드에서 "횟수를 모두 사용했어요"라고 뜨나요?

免费版每天 AI 2 次、引导 2 次（新建/恢复/重新开始都计 1 次）。夜间 22:00–06:00 为无限模式，不消耗次数。超出后入口会引导至订阅页；语音速记无配额时自动降级为单步任务，不打断你。

Free tier allows AI 2×/day and Focus 2×/day (new/resume/restart each count). Night mode 22:00–06:00 is unlimited. Over-quota routes to the subscription page; voice memo auto-degrades to a single step without blocking you.

無料版は AI 1日2回・ガイド 1日2回（新規／再開／再開は各1回カウント）。夜間22:00〜06:00は無制限モードで回数を消費しません。超過すると登録ページへ案内されます。音声メモは割当がない場合、自動で単一ステップに格下げされ、作業を中断しません。

무료판은 AI 하루 2회·가이드 2회(신규/재개/다시 시작 each 1회 카운트). 야간 22:00–06:00는 무제한 모드로 횟수를 소비하지 않습니다. 초과 시 구독 페이지로 안내됩니다. 음성 메모는 할당이 없으면 자동으로 단일 단계로 격하되어 작업을 끊지 않습니다.

我的数据存在哪？换手机怎么办？ Where is my data? How to move to a new phone? データはどこにありますか？機種変更はどうすればいいですか？ 내 데이터는 어디에 있나요? 폰을 바꾸면 어떻게 되나요?

所有任务、心情、设置都只存在你当前设备本地（无账号、无云同步）。换手机时，请先用系统 iCloud / iTunes 整机备份与恢复 把 App 连同数据一并迁移；或在 Pro 下用 PDF 导出 留存重要任务。我们暂不提供独立云端同步。

All tasks, mood, and settings live only on your current device (no account, no cloud sync). To switch phones, use iOS iCloud / iTunes full backup & restore to migrate the app with its data, or use Pro PDF export to keep important tasks. We don't offer standalone cloud sync yet.

すべてのタスク・気分・設定は「現在の端末ローカル」のみに存在します（アカウント・クラウド同期なし）。機種変更時は、まず iOS の iCloud / iTunes 端末丸ごとバックアップと復元 でアプリとデータをまとめて移行するか、Pro の PDF出力 で重要なタスクを保存してください。現時点で独立したクラウド同期は提供していません。

모든 작업·기분·설정은 '현재 기기 로컬'에만 존재합니다(계정·클라우드 동기화 없음). 기기 변경 시 먼저 iOS iCloud/iTunes 전체 백업 및 복원으로 앱과 데이터를 함께 이전하거나, Pro의 PDF 내보내기로 중요한 작업을 보관하세요. 별도 클라우드 동기화는 현재 제공하지 않습니다.

AI 功能没反应 / 一直转圈？ AI features not responding / spinning? AI機能が反応しない／ずっと読み込み中ですか？ AI 기능이 반응하지 않나요 / 계속 돌아가나요?

依次排查：① 是否处于免费额度外（看上面"次数用完"）；② 网络是否正常（AI 需联网经代理调用大模型）；③ 夜间无限模式不影响联网本身。若仍失败，多为网络环境对代理域名限制，可切换网络重试。

Check: ① free quota exceeded (see above); ② network up (AI needs internet to call the model via proxy); ③ night mode doesn't affect connectivity. If it still fails, your network may restrict the proxy domain — try another network.

順に確認：① 無料枠外か（上の「回数がなくなりました」参照）② ネットワークは正常か（AIはプロキシ経由でLLMを呼び出すため通信が必要）③ 夜間無制限モードは通信そのものには影響しません。それでも失敗する場合は、ネットワーク環境がプロキシのドメインを制限している可能性が高く、別のネットワークでお試しください。

순서대로 확인: ① 무료 할당 외인지(위 '횟수 소진' 참고) ② 네트워크 정상인지(AI는 프록시 경유로 LLM 호출하므로 인터넷 필요) ③ 야간 무제한 모드는 연결 자체에 영향 없음. 그래도 실패하면 네트워크가 프록시 도메인을 제한하는 경우가 많으니 다른 네트워크로 재시도하세요.

小组件（Widget）不显示 / 空白？ Widget blank / not showing? ウィジェットが表示されない／空白ですか？ 위젯이 안 보이나요 / 빈 칸인가요?

① 长按主屏幕空白处 → 点左上 + → 搜索 Stepping → 添加"今日任务"或"专注"小组件；② 确认已在 App 内创建任务并标星今日聚焦；③ 若仍空白，重启设备一次通常解决 iOS 小组件缓存问题。

① Long-press home screen → tap + → search Stepping → add "Today" or "Focus" widget; ② make sure you have tasks starred in Today Focus; ③ if still blank, a device restart usually fixes iOS widget cache.

① ホーム画面の空白を長押し → 左上の ＋ → 「Stepping」を検索 → 「今日のタスク」または「集中」ウィジェットを追加 ② アプリ内でタスクを作成し「今日のフォーカス」に星を付けているか確認 ③ それでも空白の場合、端末を一度再起動すると iOS のウィジェットキャッシュ問題が解消することが多いです。

① 홈 화면 빈 곳을 길게 누름 → 좌상단 + → 'Stepping' 검색 → '오늘의 할 일' 또는 '집중' 위젯 추가 ② 앱 내에서 작업을 만들고 오늘의 집중에 별표했는지 확인 ③ 그래도 빈칸이면 기기 재시작이 iOS 위젯 캐시 문제를 보통 해결합니다.

语音速记没反应 / 识别不了？ Voice memo not working? 音声メモが反応しない／認識できませんか？ 음성 메모가 반응하지 않나요 / 인식이 안 되나요?

语音速记依赖 Apple 语音识别，需两项授权：麦克风 与 语音识别。去 系统设置 → Stepping 确认两者均已开启；首次使用会弹系统授权框，请点"允许"。识别出的文字可选"AI 拆解"进一步生成步骤。

Voice uses Apple Speech and needs two permissions: Microphone and Speech Recognition. In Settings → Stepping ensure both are on; grant the system prompt on first use. You can then "AI Breakdown" the transcript.

音声メモは Apple の音声認識に依存し、2つの許可（マイク と 音声認識）が必要です。設定 → Stepping で両方がオンになっているか確認してください。初回はシステムの許可ダイアログが出るので「許可」をタップします。認識されたテキストは「AI分解」でさらにステップを生成できます。

음성 메모는 Apple 음성 인식에 의존하며 마이크와 음성 인식 두 권한이 필요합니다. 설정 → Stepping에서 둘 다 켜져 있는지 확인하세요. 첫 사용 시 시스템 권한 창이 뜨면 '허용'을 누릅니다. 인식된 텍스트는 'AI 분해'로 단계를 더 생성할 수 있습니다.

通知不推送？ No notifications? 通知が来ませんか？ 알림이 오지 않나요?

① 系统设置 → Stepping → 通知 已开启；② App 内「设置 → 通知」里相应开关（每日摘要 / 规划提醒 / 整理时刻）已打开；③ iOS 的"专注模式"可能静音通知，请检查。

① Settings → Stepping → Notifications enabled; ② in-app Settings toggles (daily summary / plan reminders / tidy moment) on; ③ iOS Focus mode may silence them — check it.

① 設定 → Stepping → 通知 がオン ② アプリ内「設定 → 通知」の各スイッチ（毎日のサマリー／計画リマインダー／整理タイミング）がオン ③ iOS の「集中モード」が通知を消音する場合があるのでご確認を。

① 설정 → Stepping → 알림 켜짐 ② 앱 내 '설정 → 알림'의 각 스위치(매일 요약/계획 알림/정리 시간) 켜짐 ③ iOS '집중 모드'가 알림을 음소거할 수 있으니 확인하세요.

怎么清除数据 / 重置？ How to clear / reset data? データを消去／リセットするには？ 데이터를 어떻게 지우고 / 초기화하나요?

App 内「设置 → 清除数据」会清空本地全部任务、心情与偏好（不可恢复，请先导出重要项）。也可直接卸载 App 删除所有本地数据。

In-app Settings → Clear Data wipes all local tasks, mood, and preferences (irreversible — export first). Uninstalling the app also deletes everything local.

アプリ内「設定 → データを消去」ですべてのローカルタスク・気分・設定を削除します（復元不可、重要な項目は事前にエクスポートを）。アプリをアンインストールしてもすべてのローカルデータが削除されます。

앱 내 '설정 → 데이터 지우기'는 로컬 작업·기분·설정을 모두 삭제합니다(복구 불가, 중요한 항목은 먼저 내보내기). 앱을 삭제해도 모든 로컬 데이터가 지워집니다.

字号太小 / 想放大？ Text too small / want larger? 文字が小さい／大きくしたいですか？ 글자가 너무 작아요 / 키우고 싶어요?

App 内「设置 → 字号缩放」可整体放大界面文字，并会跟随系统"动态字体"设置。

In-app Settings → Font Size scales the whole UI and respects iOS Dynamic Type.

アプリ内「設定 → 文字サイズ」で画面全体の文字を拡大でき、iOS の「動的タイプ」設定にも追従します。

앱 내 '설정 → 글자 크기'에서 화면 전체 글자를 키울 수 있고 iOS '동적 글자형' 설정도 따릅니다.
